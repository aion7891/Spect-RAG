Run it yourself

The pip package runs the same stages; each step above names the function that does it. Its chunker keeps headings in the chunk text, and its entity rules and default settings differ from the teaching version, so on this toy corpus it picks different chunks. Start from the quick start.

from spectrafuse import SpectRAGIngestion, SpectRAGRetrieval

SpectRAGIngestion("my_index").ingest("docs/")             # Table 1: chunk, embed, graph, spectral

search = SpectRAGRetrieval("my_index")
result = search.search(QUESTION, token_budget=4000)        # Table 2: seeds, expand, re-score, select
print(result["prompt"])

# plug in any LLM for the last stage: a function prompt -> text
out = search.answer(QUESTION, llm_fn=my_llm, token_budget=4000)
print(out["answer"])
